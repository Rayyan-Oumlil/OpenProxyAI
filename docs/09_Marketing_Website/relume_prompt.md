## Project Name: OpenProxyAI Enterprise Website

## Company Description

OpenProxyAI is a security-first AI governance platform that acts as a Zero Trust gateway between enterprise applications and LLM providers such as OpenAI, Anthropic, Azure, Bedrock, and local models.

It enables organizations to:

- Enforce real-time AI usage policies
- Maintain immutable audit logs (90 days to 7 years)
- Prevent sensitive data leakage (PII, PHI, financial data, API keys)
- Achieve compliance readiness (SOC 2 in progress, HIPAA-ready, GDPR)
- Monitor and control AI costs across teams
- Centralize governance of enterprise AI usage

Built specifically for CISOs and security teams in regulated industries.
